# KENTO（将棋 検討ツール）

盤面で駒を動かすと、将棋エンジンが候補手と読み筋を出し、AI（LLM）がその局面を日本語で解説してくれる、Windows用のツールです。
棋譜（KIF）を読み込んで、一局まるごとの評価値グラフを作ったり、AIに講評を書かせたりもできます。

> 個人が趣味で作ったツールです。動作の保証はありません。使い方や不具合のご連絡は、配布元（GitHubの場合はIssues）へお願いします。

## できること

- **盤面の検討**：駒をクリックして動かすと、エンジンが候補手（既定は3手）と読み筋を出します。候補手をクリックすると、盤面に矢印が出ます。
- **AIによる局面の解説**：エンジンの候補手と読み筋をAIに渡して、形勢と方針を日本語で解説させます（要APIキー）。解説は自動で保存されます。
- **棋譜の読み込みと保存**：KIF/KIFUファイルの読み込み、クリップボードからの貼り付け、KIFでの保存ができます。棋譜に付いている「＊」のコメント（中継の解説など）も表示でき、AIへの解説の材料にもなります。
- **全局を解析（評価値グラフ）**：一局の全局面をエンジンで解析し、評価値の流れをグラフにします。疑問手（?!）・悪手（?）・大悪手（??）の印が付き、グラフをクリックするとその局面に飛べます。結果は保存され、次回は開くだけで見られます。
- **全局をAIで講評**：解析結果（勝負所と最善手）をAIに渡して、一局の講評を書かせます（要APIキー）。
- **詰みを探す**：詰将棋の局面で、エンジンの詰み探索を使って詰み手順を探します。
- **スクショから局面を読み取る**：画面の盤面を撮影して局面にします。**将棋ソフト「棋桜」（Steam）専用**で、読み取りの精度は9割ほどです。間違いは、編集モードで直してください。ほかのソフトの画面は、うまく読めません。
- **KIFに評価値と読み筋を書き出す**：全局を解析したあとにKIFで保存すると、各手のコメントに、評価値とエンジンの読み筋（第1候補）が入ります。

AIを使わない機能（エンジンの検討、棋譜の読み込みと保存、全局解析と評価値グラフ、詰み探索）は、APIキーなしで使えます。

## 必要なもの

| もの | 内容 |
| --- | --- |
| パソコン | Windows 10 / 11（メモリ8GB以上を推奨） |
| Python | 3.10以上。無料です |
| 将棋エンジン | USI形式のエンジン（「水匠」「やねうら王」など）。**このZIPには入っていません** |
| AIのAPIキー | AIの解説・講評を使う場合だけ必要です。取得の手順は後ろに書きました |

## インストールのしかた

### 1. Pythonを入れる（初めての場合だけ）

1. <https://www.python.org/downloads/> から、Pythonをダウンロードして実行します。
2. 最初の画面の下にある **「Add python.exe to PATH」に、必ずチェックを入れて**から、インストールしてください。

### 2. このフォルダを好きな場所に置く

ZIPを解凍してできた `KENTO` フォルダを、好きな場所に置きます（例：`C:\tools\KENTO`）。
`Program Files` の中のような、書き込みが制限される場所は避けてください。設定や解析結果は、このフォルダの中に保存されます。

### 3. 必要な部品を入れる

`setup.bat` をダブルクリックします。黒い画面が開いて、部品（PyQt6、python-shogi、OpenCV、numpy）が自動で入ります。最後に「続行するには何かキーを押してください」と出たら、完了です。

### 4. 将棋エンジンを入れる

KENTOは、エンジンの本体（`.exe`）を持っていません。別に入手してください。

- **水匠**：「水匠5」などで検索して、配布ページからダウンロードします。
- **やねうら王**：<https://github.com/yaneurao/YaneuraOu> から入手します。

エンジンの利用条件は、それぞれの配布ページで確認してください。評価関数ファイル（`eval` フォルダの `nn.bin` など）は、エンジンの説明書どおりに、`.exe` と同じ場所に置いてください。

CPUに合う版を選びます。迷ったら、AVX2版が多くのパソコンで動きます。

### 5. 起動して、エンジンを登録する

1. `start.bat`（または `kento.vbs`）をダブルクリックします。
2. 右上の **「設定…」** を押します。
3. 「エンジン（exe）」の欄の「参照…」ボタンから、さっき入手したエンジンの `.exe` を指定して、OKを押します。
4. 盤面の駒を動かすと、エンジンが検討を始めます。初回は、エンジンの起動に少し時間がかかります。

起動しないときは、同じフォルダの `kento_error.txt` を開いて、内容を確認してください。

## 設定の目安

「設定…」の画面で、次の項目を変えられます。

- **スレッド数・ハッシュ(MB)**：既定は、スレッド4、ハッシュ512MBです。メモリの少ないパソコンでは、ハッシュを小さくしてください。
- **思考時間(秒)・候補手の数**：既定は、5秒、3つです。
- **全局解析：1手あたり(秒)**：既定は1秒です。長くするほど正確ですが、時間もかかります。
- **詰み探索の時間(秒)**：「詰みを探す」の制限時間です。既定は60秒です。
- **評価関数フォルダ**：エンジンの評価関数（`eval` フォルダ）が別の場所にあるときに指定します。
- **全局解析の並列エンジン数**：同時に動かすエンジンの数です。パソコンのコア数より多くしないでください。4コアなら、3が目安です。
- **解説に使うAI・各社のAPIキーとモデル名**：次の項目を見てください。

## AI（LLM）のAPIキーの取得

AIの解説と講評に使います。**1社だけ**取れば使えます。
料金や無料枠は、よく変わります。登録の前に、各社の最新の案内を確認してください。画面の表示も、変わることがあります。

| サービス | 取得先 | 費用の目安 |
| --- | --- | --- |
| Gemini（Google） | <https://aistudio.google.com/apikey> | 無料枠あり（回数に制限があります） |
| Claude（Anthropic） | <https://console.anthropic.com/> | 有料（先にクレジットを購入します） |
| OpenAI（GPT） | <https://platform.openai.com/api-keys> | 有料（先にクレジットを購入します） |
| Groq | <https://console.groq.com/keys> | 無料枠あり |
| OpenRouter | <https://openrouter.ai/keys> | 無料（:free）モデルあり |
| Mistral | <https://console.mistral.ai/> | 無料枠あり（ただし回数の制限がとても厳しいです） |
| Qwen（Alibaba Cloud） | Alibaba CloudのModel Studio（国際版） | 無料枠・有料あり |

### 取得の流れ（どのサービスも、ほぼ同じです）

1. 上の取得先を開いて、アカウントを作ります（メールアドレスなどで登録します）。
2. 「API Keys」「APIキー」といった項目から、新しいキーを作ります。
3. 表示された文字列（`sk-` や `AIza` などで始まる長い文字列）をコピーします。**あとから見られないサービスが多いので、すぐに保存してください**。
4. KENTOの「設定…」を開いて、AIの種類を選び、「APIキー」の欄に貼り付けます。モデルは、候補から選ぶか、直接入力します。

Qwenは、接続先のURLも必要です。Model Studioの画面に出る「OpenAI互換」のURLを、設定画面のURLの欄に入れてください。

### どれを選べばよいか

- 無料で試すなら、**Gemini** か **Groq** です。
- 解説の質を重視するなら、**Claude** や **GPT** が良いようです。
- 小さなモデル（Mistralの小型など）は、読み筋を取り違えたり、事実と違うことを書いたりしやすいので、解説にはおすすめしません。
- AIの解説は、間違うことがあります。エンジンの評価値と読み筋が、正しい根拠です。

### キーを守るために

- APIキーは、このフォルダの `config.json` に、**文字のまま保存されます**。
- `config.json` を、他人に渡したり、GitHubなどに載せたりしないでください。キーを使われると、お金がかかることがあります。
- キーが漏れたときは、そのサービスのページで、キーを削除して作り直してください。

## 使い方

### 棋譜を読み込む

- **KIF読込**：ファイルを選びます。
- **KIF貼付**：クリップボードにコピーしたKIFを読み込みます。盤面の図だけでも読めます（詰将棋の初形など）。
- 盤の左の棋譜欄で、手をクリックすると、その局面に飛べます。「◀ 1手戻る」「1手進む ▶」や、キーボードの左右の矢印でも動かせます。
- 棋譜に「＊」のコメントがある手では、盤の右上にコメントが出ます。コメントのある手には、棋譜欄に💬が付きます。

### 一局を通して見る

1. 棋譜を読み込んで、**「全局を解析（評価値グラフ）」** を押します。止めるには、もう一度押します。
2. 終わると、グラフが出ます。赤や橙の点が、悪手などの印です。点やグラフをクリックすると、その局面に飛べます。
3. 結果は、`解説保存` フォルダの `評価グラフ` に保存されます。あとで **「評価グラフを開く…」** で、棋譜ごと開けます。
4. **「全局をAIで講評」** で、AIが一局の講評を書きます。講評も、同じファイルに保存されます。
5. **「KIF保存」** で、評価値と読み筋をコメントに入れたKIFを書き出せます。

### 局面を解説させる

1. 解説してほしい局面にして、検討が終わるのを待ちます（「自動で検討」がオンなら、自動で始まります）。
2. **「この局面を解説する」** を押します。
3. 解説は、`解説保存` フォルダに自動で保存されます。「保存した解説を開く…」で、あとから見られます。
4. AIを使わずに、チャットに貼りたい場合は、**「文章をコピー」** で、AIに渡す文章をコピーできます。

### 詰将棋を解く

詰将棋の局面を出して、**「詰みを探す」** を押します（詰将棋の棋譜を読み込むと、最初の局面が出ます）。止めるには、右の「停止」を押します。エンジンの種類によっては、うまく動かないことがあります。

### スクショから局面を作る（棋桜専用）

1. 棋桜の画面を、**Win + Shift + S** などで撮影して、クリップボードに入れます。
2. **「スクショ→局面（クリップボードの画像）」** を押します。
3. 読み取りの間違いは、**「編集モード」** で、駒をクリックして直します。必要なら **「手番切替」** も押します。
4. 全画面を撮影して読み取る **「画面を撮影→局面」** も使えます（棋桜を全画面にしておきます）。

精度は9割ほどで、駒の取り違えが出ることがあります。棋桜以外の画面には、対応していません。

## 保存されるもの

- `config.json`：設定とAPIキー（「設定…」を保存すると作られます）
- `解説保存` フォルダ：解説、評価グラフ、AIの講評

## 困ったときは

| 症状 | 対処 |
| --- | --- |
| `setup.bat` でエラーが出る | Pythonが入っていないか、PATHに入っていません。Pythonを入れ直して、「Add python.exe to PATH」にチェックを入れてください |
| 起動しない | `kento_error.txt` を開いて、内容を確認してください |
| 「エンジンが登録されていません」と出る | 「設定…」から、エンジンの `.exe` を指定してください |
| エンジンが動かない・すぐ終了する | エンジンの版（AVX2など）が、お使いのCPUに合っていません。別の版を試してください。評価関数ファイル（`nn.bin`）が、`.exe` と同じ場所にあるかも確認してください |
| 検討が遅い | 設定で、スレッド数を増やすか、検討の秒数を短くしてください。ほかの重いソフトは閉じてください |
| AIの解説が出ない | 設定で、AIの種類とAPIキーが合っているか確認してください。無料枠の回数制限や、課金の残高切れのこともあります |
| AIの返事が、盤面と合っていない | 小さなモデルでは、よく起きます。大きなモデルで試してください |

## ご注意

- AIの解説と講評は、間違うことがあります。必ず、エンジンの評価値と読み筋を、根拠にしてください。
- 「この局面を解説する」や「全局をAIで講評」を使うと、局面の情報（と、棋譜にコメントがあればその内容）が、選んだAIサービスに送られます。
- 棋譜に付いているコメント（中継記事の文章など）には、著作権があります。コメントつきの棋譜やKIFを、ほかの人に公開するときは、ご注意ください。
